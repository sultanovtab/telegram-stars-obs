# starchik v4 — Telegram Stars → OBS

Cloudflare Worker для `@ttt_stars_bot`.

## Что добавлено в v4

- Опциональная TTS-озвучка комментария: базовый профиль `Стандартная` включён по умолчанию и стоит `+10 ⭐`.
- 5 голосовых слотов в `/admin` (`Стандартная`, `Премиум`, `Премиум+`, `Ультра`, `Ультра+`). Зритель видит только включённые слоты.
- В админке можно включать/выключать голосовой слот, менять его цену и название, запускать тест озвучки.
- Анимационный tier считается по **основной** сумме доната, а доплата за TTS не повышает tier. Пример: 100 ⭐ + 10 ⭐ TTS остаётся tier 100–249.
- Алерт больше не исчезает слишком рано: длительность автоматически растёт вместе с длиной комментария; при TTS он остаётся на экране до окончания речи (с безопасным timeout).
- `🎯 Цель сбора` с отдельным OBS Browser Source и оранжевой progress bar.
- Цель использует реальный текущий баланс бота через официальный `getMyStarBalance` Telegram Bot API.
- Виджет цели обновляется сразу после платежа и дополнительно сверяет баланс примерно каждые 30 секунд.
- `/admin` → `💰 Баланс` показывает реальный доступный Stars-баланс.

Все настройки v3 сохраняются: `overlayKey`, суммы, GIF/видео, звуки, история и claim владельца остаются в Durable Object.

## Обновление с v3

Новых Cloudflare Secret не требуется.

1. Загрузи содержимое архива v4 поверх файлов в GitHub `telegram-stars-obs`.
2. Commit changes.
3. Дождись автоматического Cloudflare deployment.
4. Старую OBS-ссылку алертов менять не нужно.
5. Открой `/admin` в Telegram — появятся новые пункты `🗣 Озвучка`, `🎯 Цель сбора`, `💰 Баланс`.

## Озвучка

Путь зрителя:

1. Выбирает основную сумму Stars.
2. Пишет комментарий.
3. Если есть включённые TTS-профили, бот предлагает, например, `🔊 Стандартная +10 ⭐` или `Без озвучки`.
4. Перед оплатой бот показывает основную сумму и доплату. Сам Telegram invoice получает одну итоговую сумму — для `XTR` Telegram требует ровно один `LabeledPrice`.
5. После `successful_payment` OBS показывает алерт и зачитывает комментарий.

`/admin` → `🗣 Озвучка`:

- включить/выключить профиль;
- изменить доплату;
- переименовать;
- тестировать без списания Stars.

Сейчас профили используют системный Speech Synthesis в OBS/CEF с разными базовыми параметрами. Дополнительные внешние/кастомные голоса можно подключить позже к уже готовым слотам.

### Важное про звук OBS

Speech Synthesis работает внутри CEF Browser Source. На некоторых версиях OBS, если включено **Control audio via OBS**, SpeechSynthesis может не попадать в отдельный Browser Source audio channel. Если TTS видно, но не слышно в стриме, сначала выключи `Control audio via OBS` у этого Browser Source и убедись, что OBS захватывает Desktop Audio. Обычные загруженные alert-звуки продолжают работать как раньше.

## Цель сбора

`/admin` → `🎯 Цель сбора`:

- включить/скрыть виджет;
- задать название, например `На новое кресло`;
- задать цель, например `1000 ⭐`;
- принудительно обновить баланс;
- получить отдельные OBS-ссылки для 1920×1080 и 1080×1920.

Прогресс = текущий доступный баланс Telegram Stars / заданная цель. Если Stars будут выведены или возвращены, шкала тоже изменится после синхронизации.

## Старые функции

- Telegram Stars (`XTR`) через `sendInvoice`.
- Алерт только после `successful_payment`.
- Комментарии.
- OBS Browser Source 1920×1080 и TikTok 1080×1920.
- WebSocket realtime, очередь и reconnect.
- GIF/WebM/MP4/картинки/video-стикеры по tier.
- Звуки/voice по tier.
- История платежей.
- `/terms`, `/paysupport`.
- Ротация защищённого OBS key.
